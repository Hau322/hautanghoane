TRANG WEB TẶNG HOA 20/10

Cách chạy:
1. Giải nén thư mục flower_gift_website.
2. Mở index.html bằng trình duyệt để xem.
3. Nếu dùng XAMPP: chép cả thư mục vào htdocs rồi truy cập http://localhost/flower_gift_website/

Các file:
- index.html: nội dung giao diện
- style.css: màu sắc, bố cục, responsive
- script.js: hiệu ứng hoa bay và nút chia sẻ/copy
- assets/: background, ảnh mèo và hoa đã xử lý nền

Lưu ý:
- Nút Copy lấy URL hiện tại của trang. Sau khi upload lên hosting, link chia sẻ sẽ là link website thật.
- Ảnh hoa nguồn có checkerboard/watermark trong ảnh gốc; bản tách nền tự động có thể còn vài viền chưa hoàn hảo. Có thể thay các file PNG trong assets nếu muốn tinh chỉnh thêm.
